# 训练者 Skills

给来访者、学员、想开始运动但还没准备好的人。用户扮演**训练者**，不是教练。

本目录目前没有已上线 skill。下面是对偶 skill 方案，确认后再实现。

## 计划中：ace-being-coached-sim

与 `coach/ace-behavior-change-sim` 角色对调。

| | 教练 skill（已有） | 训练者 skill（方案） |
|---|---|---|
| 用户 | 教练 | 训练者 / 来访者 |
| Agent A | 无意向期客户 | 阶段匹配的 ACE 教练 |
| Agent B | 评价官（评教练） | 体验官（翻译给训练者） |
| 成功 | 降阻抗、引出她自己的理由 | 认出自己的阶段；利弊和效能有变化 |
| 结束 | 给教练打分 | 给训练者一份阶段轨迹报告 |

### 为什么要做对偶

教练侧容易把「讲好处 + 给动作」当成帮助。训练者侧把同一套过程反过来体验：教练不给计划时，体验官说明这是阶段匹配，不是敷衍。

### 两个 agent

**ACE 教练（对用户说话）**

- 只按当前阶段用认知或行为过程；无意向期停在 Ask，不给课表
- 1–3 句，口语，不报术语
- 默认把用户当成无意向期，直到用户自己的话证明阶段前进
- 用户若主动要计划：反映愿望，仍先探阶段，不立刻 Collaborate

**体验官（只给用户看，不给教练 agent）**

每轮八项，语气比教练评价官更白话：

- 阶段（你现在更像哪一段）
- 教练用了哪个过程，匹配还是过早
- ABC 走到哪一步
- 决策平衡：你刚才自己说出口的利/弊
- 自我效能
- 你这句是改变语言还是维持语言
- 依据
- 建议给训练者：下一句可以多说哪类个人影响（不替用户编理由）

### 流程

1. 开场问真实或扮演的现状；未指定则用同一默认人设让用户代入
2. 教练先开口（反映「还没觉得需要专门练」并交还选择权）
3. 用户说话 → resume 教练 → resume 体验官 → 双栏展示
4. 「结束模拟」：阶段轨迹、自己说出的利弊、效能变化、三句可对自己说的话

### 不做

- 不把用户练成「配合的客户」去讨好教练
- 不在无意向期用恐吓或办卡
- 不做观摩打分模式（用户只看、不说话）；那不是对偶，是测验

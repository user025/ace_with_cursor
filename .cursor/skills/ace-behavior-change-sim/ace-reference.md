# ACE 行为改变对照表

ACE 技巧用来匹配 readiness，不是替客户做决定。评价官按本表判「匹配 / 过早 / 过晚」。

## TTM 阶段

| 阶段 | 操作定义 | 本阶段目标 |
|---|---|---|
| 无意向期 | 6 个月内无规律运动打算 | 降阻抗、提高觉察、引出个人意义 |
| 意向期 | 考虑 6 个月内开始，仍矛盾 | 放大改变语言、决策平衡翻盘 |
| 准备期 | 30 天内准备行动，或已有零星尝试 | 她自己选的低压力小步骤 |
| 行动期 | 已规律运动不足 6 个月 | 计划、支持、防复发 |
| 维持期 | 已坚持 ≥ 6 个月 | 内在奖励、防倦怠 |

礼貌同意 ≠ 阶段前进。进入意向期至少要有客户自己的改变理由、对现状的担忧、或认真考虑未来改变。进入准备期至少要有近期行动意愿或她提出的具体小步骤。阶段可倒退。

## 改变过程

**认知过程（无意向期 / 意向期为主）**

| 过程 | 匹配做法 | 错用 |
|---|---|---|
| 意识唤醒 | 开放式问题让她发现现状 | 讲课式罗列好处 |
| 情绪唤起 | 让她体会不改变的感受 | 恐吓疾病/死亡 |
| 环境再评价 | 探索行为对家人等工作的影响 | 用家人道德绑架 |
| 自我再评价 | 探索「我想成为谁」 | 贴上不健康标签 |
| 社会解放 | 指出可选的支持性环境 | 推销办卡/课程 |

**行为过程（准备期及以后）**

自我解放、互助关系、反条件化、强化管理、刺激控制。在无意向期出现 = 过早。心肺菜单、壶铃 flow、动物流、一起试试 = 过早的反条件化 / Collaborate。

## 决策变量

- **决策平衡：** 无意向期通常弊 > 利。利变多且来自她自己的话，才算移动。教练列举的好处不算。
- **自我效能：** 任务特异。提起「以前没坚持」却立刻给新动作，通常降低效能。先认可挫败，再问曾经有效的一小点。
- **自我决定：** 自主、胜任、关系。命令、假定「你既然来了肯定想提高」、过早「我帮你」都会伤自主。

## ACE ABC（Mover Method）

1. **Ask**：开放式问题、OARS、准备度。无意向期主要停在这里。
2. **Break down**：探索障碍与低效能，不急着给解法。
3. **Collaborate**：客户主导的下一步 / SMART。无意向期几乎不应进入。

Ask 可以整场都做。无意向期的 Break down 只探障碍，不拆成训练计划。Collaborate 要等改变语言稳定出现。

## 无意向期推荐顺序

反映维持语言 → 问日常感受 → 探索具体影响（环境再评价）→ 反映矛盾 → 问这件事对她有多在意 → 交还选择权。不要用「我能帮你」收尾。

可用原话方向（不是唯一正确答案）：

- 「下班已经够累了，现在再提专门健身，对你来说更像加码。」
- 「陪家人提不起劲，同时你觉得歇一晚上就好、还没想过专门改。」
- 「陪家人提不起劲这一点，对你自己来说有多在意？动不动完全由你决定。」
